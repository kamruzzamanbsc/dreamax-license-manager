# Security policy

Do not publish a suspected vulnerability in a public issue before maintainers have had a reasonable chance to investigate. Report the affected version, impact, minimal reproduction, and suggested remediation through the official security contact once `SUPPORT_URI` is resolved before release. Never include real license keys, API credentials, customer data, database dumps, or the master key.

This development package has not completed its release security gates. Review `docs/THREAT-MODEL.md` and `docs/FREE-V1-MUST-PASS.md` before testing.
