# Contributing

Work on one bounded milestone at a time. Begin by stating inspected context, goal, assumptions, blockers, and security/migration risk. Keep hook adapters thin, preserve public v1 contracts, add tests and documentation with code, and never weaken the frozen reference client to hide a breaking change.

End with outcome, files changed, compatibility impact, security considerations, exact commands/results, unverified work, and the next smallest safe milestone. Do not claim production readiness without release-gate evidence.
