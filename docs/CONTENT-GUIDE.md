# Plain-language content guide

| Internal fact | Merchant/customer wording |
| --- | --- |
| `available` | Available for sale |
| `assigned` | Delivered |
| `suspended` | Temporarily disabled |
| `revoked` | Permanently revoked |
| computed expired | Expired |
| one or more active rows | In use on one or more installations |
| positive limit fully used | All activation slots are in use |

Primary badge precedence is Permanently revoked, Temporarily disabled, Expired, then lifecycle wording. Capacity is a secondary warning only while otherwise eligible. Always show factual usage separately: “2 of 3 in use,” “All 3 slots in use,” or “Unlimited; 2 in use.”

Before a high-impact action, name the customer, order, product, activations, expiry effect, whether the key remains usable, and whether the action is reversible. Recovery copy must say that the database plus external encryption key are required without exposing paths or secret values.
